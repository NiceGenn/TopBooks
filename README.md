# Между строк · TopBooks

Веб-приложение для личного списка из 118 книг. Сохраняет нумерацию, четыре уровня сложности, статусы и все столбцы Excel. Основной вид — список; дополнительно есть карточки, поиск, фильтры, обложки, описания и заметки.

## Запуск

Нужны Node.js 24 и npm, для импорта — Python 3.12+ без дополнительных пакетов.

```bash
npm ci --cache /tmp/topbooks-npm-cache
npm run dev -- --port 5173
```

```bash
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют системный `/usr/bin/chromium`. Для другого установленного Chromium:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/путь/к/chromium npm run test:e2e
```

Production-сборка: `dist/`; локальная проверка: `npm run preview -- --port 4173`.

## Возможности

- Все 118 книг, исходные номера, 4 уровня; дополнение №104–118 показано внутри соответствующих уровней.
- Поиск по названию, автору и содержимому исходных полей; фильтры по уровню, жанру, статусу, наличию бумажной книги.
- Два вида списка, сортировка, раскрытие всех исходных столбцов.
- При наведении — обложка и краткая информация; при открытии — описание, «Что даст книга», ссылки, прогресс и заметки.
- Сохранение в браузере, резервная копия JSON и восстановление на другом устройстве или домене.
- Исходный Excel можно скачать из приложения; оригинал находится в `sources/`.
- Выбор собственной обложки и прямых ссылок на издание в карточке.

## Данные

Исходник: [`sources/Книги — дополненный список 118.xlsx`](sources/Книги%20—%20дополненный%20список%20118.xlsx).

```bash
npm run import:books
```

Импорт не требует openpyxl, не выполняет формулы, не воспринимает содержимое документа как команды. Генерирует `src/data/books.json`. Проверяет уникальность и полный диапазон ID 1–118; поддерживает номера, записанные текстом (№9). Итоги рассчитываются по записям: 32 / 42 / 29 / 15 книг по уровням, 5 прочитано, 1 читается в исходнике. У 15 добавленных книг страницы не указаны.

Редакционные описания находятся отдельно в `src/data/descriptions.json`. Названия №77 и №87 требуют уточнения, №101 сокращено в источнике. Исходные значения не исправлены догадками.

## Сохранение и приватность

Статическое приложение без сервера и регистрации. localStorage хранится отдельно для каждого браузера и origin. Нужен экспорт перед очисткой браузера, сменой домена или устройства. Новые отметки одного посетителя не меняют список других посетителей. Исходные отметки из Excel входят в общедоступную сборку.

Резервная копия JSON содержит личные заметки: храните её у себя. Восстановление заменяет личный прогресс и выбранные издания. Повреждённые копии отклоняются; повреждённое хранилище не перезаписывается автоматически.

Подтверждены 75 прямых карточек текстовых книг Яндекс Книг; сопоставление проверяет название и автора и исключает пересказы. В `src/data/editions.json` сохранены происхождение и дата проверки. Для 67 книг дополнительно проверены ISBN в Open Library (`src/data/openlibrary.json`); часть обложек сохранена локально в `public/covers/`. При недоступности Яндекса приложение пробует обложку Open Library, затем показывает типографическую. Указанное издание и язык могут отличаться.

Обложки загружаются из внешних источников: они получают обычные запросы браузера. Заметки и прогресс туда не отправляются. Наличие внешней книги и доступность обложки не гарантируются. При отказе показывается типографическая обложка. Подтверждённые ссылки открывают издание напрямую; остальные ведут на поиск, что прямо указано в интерфейсе. Для Яндекса проверен актуальный маршрут `/search/all/<запрос>`; параметр `?text=` игнорируется сервисом.

## Обновление метаданных (необязательно)

Основная сборка работает из сохранённых данных и не обращается к каталогам.

```bash
python scripts/refresh_metadata.py
python scripts/cache_openlibrary_covers.py
```

Первый скрипт обращается к публичным страницам Яндекс Книг, ограничивает частоту запросов и сохраняет только подтверждённые текстовые книги. Не использует авторизацию и не выполняет код страниц. Ответы кэшируются вне проекта в `/tmp/topbooks-metadata-pages`. Для отдельных книг: `--only 1 16`.

Второй сохраняет доступные обложки Open Library. В облачной сети часть изображений перенаправляется на `archive.org`; потребуется разрешить этот домен. Неудача внешнего запроса не ломает приложение. `--download` первого скрипта может сохранить доступные обложки Яндекса после разрешения `api.bookmate.ru`.

Проверка Читай-города из этой машины возвращает HTTP 403 с сообщением «Возможно, включён VPN» (географическое ограничение); прямые карточки не выдумывались. Используются ссылки на его публичный поиск. Для любых новых источников сохраняйте TLS-проверку и происхождение изображений.
