# Публикация на GitHub Pages

Цель: `NiceGenn/TopBooks`, ветка `main`. Приложение статическое, отдельные сервер, база и секреты не нужны.

## Что станет публичным

Названия, исходные отметки из Excel и сам Excel включены в сборку. Ваши новые локальные заметки и отметки не публикуются с кодом. Если в будущем захотите вход и синхронизацию, потребуется отдельный сервис хранения.

## 1. Первоначальная загрузка (уже выполнено)

Проект подготовлен в `/workspace/TopBooks`. Перед первым коммитом просмотрите `git status --short`. В пустом репозитории можно создать `main`, добавить файлы и отправить их в GitHub:

```bash
cd /workspace/TopBooks
git switch -c main
git add .
git commit -m "Create personal reading library from 118-book Excel list"
git push -u origin main
```

Эти команды предназначены для исходно пустого репозитория. Если `main` уже появилась, сначала получите её состояние и не перезаписывайте историю. Не используйте force push. Убедитесь, что пользователь согласен на загрузку и публикацию. Наличие read-доступа через облачный Git proxy само по себе не подтверждает push-доступ.

## 2. Включить Pages

Откройте репозиторий `https://github.com/NiceGenn/TopBooks`, затем **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Если репозиторий приватный, доступность Pages зависит от тарифа GitHub. Не делайте репозиторий публичным автоматически: это отдельное решение владельца. Вместо смены видимости можно использовать другой статический хостинг с папкой `dist`.

## 3. Запустить публикацию

В **Actions** откройте **Check and publish to GitHub Pages** и выберите **Run workflow → main**, если автоматический запуск ещё не произошёл. Workflow установит зависимости через `npm ci`, проверит повторяемость импорта, выполнит unit-тесты, production-сборку и браузерные сценарии Playwright, затем развернёт `dist`.

Ожидаемый адрес при стандартных настройках: `https://nicegenn.github.io/TopBooks/`. Это предполагаемый адрес, а не подтверждение публикации. Настоящий URL появится в успешном шаге Deploy и в Settings → Pages.

## 4. Проверить опубликованный сайт

- Открыть URL из успешного Deploy, убедиться, что стили, шрифты и скрипты загрузились под `/TopBooks/`.
- Найти «1984» и последнюю книгу №118, открыть описание и ссылки.
- Изменить отметку, перезагрузить страницу, убедиться в сохранении.
- Скачать исходный Excel и резервную копию JSON.
- Проверить мобильный экран и доступность обложек. При отказе стороннего сервиса типографическая обложка является ожидаемым резервным видом.
- Для переноса локального прогресса из тестового адреса экспортировать JSON и восстановить на опубликованном домене.

## Обновления

После публикации новые коммиты в `main` запускают тот же workflow. Личные данные посетителей остаются у них в браузере; не меняйте ключ хранилища и номера книг без миграции.

`dist` в Git не хранится. Не добавляйте в репозиторий `node_modules`, секреты или личные JSON-копии.
