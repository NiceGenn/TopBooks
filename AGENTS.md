# TopBooks / «Между строк»

## Назначение
Личная библиотека пользователя из Excel. Язык интерфейса, документации и общения — русский. Сохранять авторский список, нумерацию, четыре уровня и поля; не заменять таблицу единственным видом карточек.

## Начало задачи
- Прочитайте `MEMORY.md` и релевантные файлы в `docs/`.
- Работайте в существующем checkout. Облачная задача уже изолирована; не создавайте worktree без просьбы пользователя.
- Проверьте `git status --short`, сохраните чужие изменения.
- Используйте Node из `.nvmrc`, `npm ci --cache /tmp/topbooks-npm-cache` в облаке.

## Команды
- `npm run dev -- --port 5173` — разработка.
- `npm run build` — TypeScript и production-сборка.
- `npm test` — логика импорта, фильтров, резервных копий, ссылок.
- `npm run test:e2e` — Chromium, нужен предварительный `npm run build`. По умолчанию `/usr/bin/chromium`; для другого пути задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.
- `node scripts/check-published-site.mjs <URL>` — проверка опубликованного HTML, MIME JavaScript/CSS, Chromium, 118 книг и поиска. Сетевой доступ к URL должен быть разрешён.
- `npm run import:books` — повторный импорт исходного Excel стандартной библиотекой Python 3.12+; файл не меняет.

## Данные и ограничения
- Неприкосновенный исходник: `sources/Книги — дополненный список 118.xlsx`. Не редактировать и не удалять без явного указания.
- `src/data/books.json` генерируется импортом; править импорт или источник только по задаче, не вручную.
- ID 1–118 — постоянные ключи личного прогресса; не перенумеровывать.
- Пропуски страниц и признаков не заполнять догадками. Текст «Что даст книга» — из источника.
- `src/data/descriptions.json` — редакционные аннотации, отдельные от Excel.
- №77 и №87 требуют уточнения названия/издания. №101 сокращено в Excel. Не подменять их похожими книгами.
- Ссылки без подтверждённого издания должны явно называться поиском, не притворяться прямыми карточками.
- Обложки могут быть другого языка/издания: показывать источник, при отказе сети — типографическую заглушку. Не обходить блокировки, CAPTCHA, TLS или авторизацию.
- Личные статусы, заметки и выбранные издания — в localStorage `topbooks.library.v1`; есть JSON backup/restore. Не менять схему без миграции. Не отправлять эти данные на внешние сервисы.
- Все импортируемые ссылки проверять: только HTTPS, магазины — соответствующий домен; заметки выводить как текст, без HTML.
- Бэкенда, аккаунтов и межустройственной синхронизации нет. Не обещать их пользователю.

## Интерфейс
Светлая бумага, приглушённый зелёный, книжная типографика, спокойная плотная таблица. Проверять мобильный экран, клавиатуру, нативный dialog и hover-preview. Все исходные столбцы доступны через «Все столбцы».

## Публикация
Целевой хостинг согласован: GitHub Pages, репозиторий `NiceGenn/TopBooks`. Workflow `.github/workflows/pages.yml` собирает и публикует `dist` из `main`; `base: './'` поддерживает `/TopBooks/`. Pages должен использовать build_type=workflow; публикация исходной ветки вместо dist приводит к неработающему /src/main.tsx. Deploy job сообщает фактический режим (его смена может требовать прав владельца), а verify-site проверяет опубликованный интерфейс и сохраняет диагностику. Не объявлять сайт рабочим без успешного verify-site или эквивалентной проверки публичного URL. Не пушить и не включать публичный доступ без разрешения на фактическую публикацию. Подготовка workflow сама по себе сайт не публикует.

## Память
После значимых изменений обновляйте `MEMORY.md`: принятые решения, подтверждённые проверки, ограничения и следующий шаг. Не записывайте секреты и личные заметки пользователя. Не представляйте непроверенное как выполненное.
