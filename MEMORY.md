# Память проекта TopBooks

Обновлено: 18 октября 2026.

## Задача и решения пользователя

- Превратить личный список книг из Excel в веб-приложение, сохранив стиль списка, исходные поля и порядок.
- Обложка при наведении и открытии, описание, ссылки на Яндекс Книги и Читай-город.
- Оригинальный Excel хранить в проекте; вести AGENTS и память.
- Пользователь подтвердил **GitHub Pages** и хранение новых отметок/заметок в браузере с JSON backup/restore. Сервер и синхронизация между устройствами не входят в первую версию.
- Пользователь просил попробовать альтернативный доступ к Читай-городу. Проверены обычный HTTP, главная страница, поиск, sitemap и Chromium. HTTP возвращает 403 с «Возможно, включён VPN», страница использует geoblocked.js. Chromium этой облачной машины дополнительно не доверяет сертификату внешнего соединения; TLS-проверка не отключалась. Обходные прокси/VPN не добавлялись. Сохранены ссылки на публичный поиск.
- Пользователь явно поручил загрузить проект самостоятельно («Загрузи сам»). Загрузка в GitHub и запуск подготовленной публикации разрешены. Видимость репозитория без отдельной необходимости не менять. Успешную публикацию подтверждать отдельно от push.

## Репозиторий

`/workspace/TopBooks`, origin `NiceGenn/TopBooks` на GitHub. Изначально репозиторий был пустым, без коммитов, ветки main и файлов; локальная unborn-ветка называлась work. Приложение создано здесь. Не создавать worktree без просьбы пользователя.

## Стек и запуск

React 19 + TypeScript + Vite 6. Node.js 24 (`.nvmrc`), npm lockfile. Python 3.12+ нужен только утилитам импорта/метаданных; сторонних Python-зависимостей нет. Golos Text и Literata включены локально через @fontsource; лицензии в public/licenses. Значки lucide-react.

```bash
cd /workspace/TopBooks
npm ci --cache /tmp/topbooks-npm-cache
npm run dev -- --port 5173
```

Production: `npm run build`, затем `npm run preview -- --port 4173`. Проверки: `npm test`, `npm run test:e2e` после сборки. Для Playwright в облаке используется `/usr/bin/chromium`; CI устанавливает Chromium через Playwright.

## Метаданные и обложки

- `src/data/editions.json`: **75 подтверждённых прямых ссылок на текстовые книги Яндекс Книг** с совпадением названия и автора, датой и источником. Результаты AudioBook и краткие пересказы исключены.
- Актуальный проверенный формат поиска Яндекса — `/search/all/<URL-encoded запрос>`. `?text=`, `?q=` и `?query=` у корневой страницы поиска игнорировались и показывали пустой запрос. Не возвращать старый формат.
- `scripts/refresh_metadata.py` получает обычные публичные HTML-страницы с ограничением частоты, не исполняет JS и не использует авторизацию. Кэш в `/tmp/topbooks-metadata-pages`. Скрипт необязателен при сборке/старте.
- `src/data/covers.json` и `src/data/openlibrary.json`: **67 ISBN**, проверенных публичным API Open Library. Свидетельство первичной проверки — `docs/isbn-verification.json`. Издания могут быть англоязычными, это указано в интерфейсе.
- `public/covers/`: **21 локально сохранённая обложка**, остальные загружаются по метаданным. Для 115 книг есть источник обложки; для 3 неоднозначных записей остаётся типографический вид.
- `scripts/cache_openlibrary_covers.py` кэширует доступные изображения без отключения TLS. Часть Open Library перенаправляет на archive.org, который блокируется текущей политикой. Изображения api.bookmate.ru также блокировались прокси. Не утверждать, что все внешние изображения скачаны/проверены в браузере.
- При отказе Яндекса компонент пробует Open Library (локальный файл, если есть); затем показывает типографическую обложку. Тайм-аут 8 секунд, ошибки обрабатываются. При необходимости пользователь задаёт собственное HTTPS-изображение и прямые ссылки в карточке.
- Читай-город: поиск по `https://www.chitai-gorod.ru/search?phrase=...`; прямые карточки не подтверждены из-за 403.

## Интерфейс и сохранение

Книжный светлый интерфейс «Между строк»: таблица по четырём уровням, дополнительная сетка карточек, все исходные поля, поиск, фильтры, сортировка, hover-preview и нативный dialog. Мобильная навигация даёт доступ к заметкам и информации, таблица прокручивается вбок.

Прогресс, бумажные экземпляры, заметки и личные издания хранятся в `localStorage['topbooks.library.v1']`. Новые данные одного посетителя не изменяют исходник или данные другого. Импорт заменяет личные данные; строгая проверка схемы, ID и HTTPS-доменов. Повреждённое хранилище не перезаписывается; при ошибке записи предлагается экспорт. Записи всегда выводятся текстом, без HTML.

Запуск: https://github.com/NiceGenn/TopBooks/actions/runs/39135905430 . Job build завершился успешно (49 секунд): установка, повторяемый импорт, unit-тесты, TypeScript/production и Playwright; артефакт github-pages создан (1.11 MB).

Для включения через actions/configure-pages enablement требуется отдельный токен с административными правами; стандартного GITHUB_TOKEN workflow недостаточно (проверено по action.yml v5). Оставшееся действие владельца: https://github.com/NiceGenn/TopBooks/settings/pages → Source: GitHub Actions, затем в указанном workflow Re-run failed jobs (или Run workflow).
